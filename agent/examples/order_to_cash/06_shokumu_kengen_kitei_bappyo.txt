■ 職務権限規程(抜粋: 販売業務関係別表) 文書番号: HR-REG-010 改訂第9版(2026年4月1日施行)

本抜粋は、販売業務(受注〜回収〜クレーム対応)に関係する決裁権限の別表のみを
収録したものである。本文(決裁の原則、代決・専決、利益相反の回避等)は
原本を参照のこと。

────────────────────────────────────────
別表2 特価・販売条件の決裁権限 p.14
────────────────────────────────────────

┌──────────────────────────┬──────────────┐
│ 決裁事項                                         │ 決裁権者                     │
├──────────────────────────┼──────────────┤
│ 特価承認(値引率5%未満)                        │ 営業課長                     │
│ 特価承認(値引率5%以上10%未満)                │ 営業部長                     │
│ 特価承認(値引率10%以上)                       │ 営業本部長                   │
│ 特価承認(受注金額1,000万円以上は値引率不問)   │ 営業本部長                   │
│ キャンペーン価格の事前一括承認                   │ 営業本部長                   │
│ 支払サイトの標準(30日)からの延長(60日まで) │ 営業部長+与信管理部長合議   │
│ 支払サイトの60日超への延長                       │ 担当役員                     │
│ 受注失効の解除(失効後の同一条件再登録)        │ 営業部長                     │
└──────────────────────────┴──────────────┘

注1: 値引率は標準価格に対する率とし、複数品目の受注では受注全体の
     加重平均値引率による。
注2: キャンペーンコード適用受注は個別決裁を要しない(SLS-REG-001 第13条3項)。
